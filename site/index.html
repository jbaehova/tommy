    How does it work?

    Telegram is the screen.
    Your server does the work.

    1. 1

      Ask

      Write to your lead agent in Telegram, in plain words.

    2. 2

      Split

      It hands each part of the job to the agent that fits.

    3. 3

      Work

      Agents work on your server, each with its own files, browser and memory.

    4. 4

      Report

      You get one answer. Each agent's chat shows its part.

    What if a site asks for my password?

    You type it in Tommy, not in the chat.

    Each agent has a private browser on your server. Tap Open Tommy in its chat, and a mini app opens inside Telegram.

    • See the agent's screen

      A picture of the page the agent has open, when you ask for it.

    • Enter a password or a code

      The value goes to the page. It is never added to the chat.

    How do I install it?

    Start with one prompt.

    Your coding agent installs Tommy for you. It asks for each value it needs and shows each sudo command before it runs it.

    1. 1

      Get a server

      A Linux server that stays on: Ubuntu 24.04 or Debian 12, 4 GB of memory or more. Point a domain to it and open ports 80 and 443.

    2. 2

      Paste this into your coding agent

      Claude Code, Codex or another agent, on the server or on a computer that reaches it over SSH.

      Install Tommy for me. Read docs/INSTALL.md from this checkout, or get the guide from https://raw.githubusercontent.com/jbaehova/tommy/main/docs/INSTALL.md if I use the main branch. Follow it step by step. Ask me for every value it needs, such as my domain and my Telegram manager bot. Show me each sudo command before you run it.
    3. 3

      Make your manager bot

      Create one bot with BotFather in Telegram. Its chat is where your lead agent answers. You also need an account for Claude, ChatGPT (Codex), Cursor or Pi.

    4. 4

      Grow your team

      Send /new and say what the agent does. It gets its own bot and starts at once.

    Prefer to do it by hand? Follow the install guide, or download a Linux build from Releases.

    What can I type?

    Anything, in plain words.

    Everything happens in chat. Commands are shortcuts: type / in any chat to see them all.

    /new Tracks my budget
    Create an agent with its own bot. The text becomes its role.
    /connect
    Give an existing agent its own bot
    /agents
    List your agents and their chats
    /root
    Choose the agent that leads
    /disconnect @username
    Unlink a bot. The agent and its work stay.
    /model
    Change the model
    /engine codex
    Move the agent to Codex or Claude. It keeps its memory.
    /instructions
    Show or change what the agent does
    /routines
    Work that runs on a schedule
    /browser
    See the agent's browser tabs
    /stop
    Stop the current task
    /delete
    Delete the agent and its workspace
    sudo tommy status
    Is everything running?
    sudo tommy logs
    Follow the log
    sudo tommy agents
    List the agents and their chats
    sudo tommy restart
    Restart the service
    /

    Where does my data live?

    On your server.

    • Workspaces, conversations and the database stay on your server. Telegram keeps only the messages and files of its chats.
    • Each agent keeps its memory and identity after a restart, and after a move from Claude to Codex.
    • Run Claude, Codex, Cursor and Pi side by side. Each agent uses its own model.
    • There are no Tommy accounts. The server has one owner: you.
    • A warning. Agents have full access to the server. They read and change files, run commands and use the network. Give them only work you trust.
